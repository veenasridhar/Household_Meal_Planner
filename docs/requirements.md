## Problem Statement
Deciding what to eat today can be confusing while also keeping in mind the available ingredients and also meeting the personal nutritional goals. This application helps users manage recipes, track meal history, receive personalized meal recommendations and generate weekly meal plans.

## Functional Requirements
FR00 - Add, View Delete and Edit Recipes
FR01 - Record daily meal consumption
FR02 - Find the Nutritional value of the recipes if not available
FR03 - Provide appropriate meal recommendations (daily)
FR04 - Weekly Recommendations based on past week history
FR05 - Meal Recommendation based on available ingredients(if ingrdients are known or provided)
FR06 - Track nutritional value of cooked meals.
FR07 - Create a fixed history period
FR08 - Recipe Searcher

Meal Recommendation should ensure variety (non-repeatability), nutritional balance and available ingredients.
